ARCHIVED // V1.0 CONTEXT

🚀 V1.0 项目背景与拉踩诉求

1.0 业务背景：当前新茶饮及消费品赛道已进入红海竞争时代。各大新媒体运营团队常面临“无法实时追踪和聚合竞品最新真实舆情缺陷”以及“难以快速将我方核心防御优势（0植脂末、赤藓糖醇控糖等白皮书数据）转化为宣发语料”的短板。

📌 本项目固定企业背景案例：FreshTea 鲜茶主义

系统内置了品牌「FreshTea 鲜茶主义」的核心资产库。其核心防御策略为：全线拒绝使用植脂末与人工香精，全面采用天然赤藓糖醇，默认甜度仅为市面竞品的 1/3。

1.0 核心逻辑是当用户输入任何外部竞品（如：霸王茶姬 伯牙绝弦），系统自动捕获该竞品的大众吐槽，然后自动检索并调用 FreshTea 的成分底牌进行精准的“跨维度反击式差异化营销”。

⚙️ V1.0 同步多分支五节点原理

在 1.0 基础版中，系统通过多层大模型与网络实时检索插件进行全同步链式编排，整体拓扑包含五大核心节点：

  1. 【Start 起始节点】 $\rightarrow$ 接收透传的 `competitor_keyword` 与 `target_platform` 变量。
  2. 【网络检索与清洗层】 $\rightarrow$ 调用网页插件抓取全网关于竞品的真实大众槽点。
  3. 【知识库精确召回层 (RAG)】 $\rightarrow$ 检索我方白皮书数据并注入上下文。
  4. 【Condition-Router 条件分流器（IF 节点）】 $\rightarrow$ 根据变量分流至对应平台的大模型提示词节点。
  5. 【End 结束节点】 $\rightarrow$ 各分流节点产出数据后，由于扣子平台只能有一个输出，后端采用多输出判空逻辑，最终由网关同步阻塞拦截回传前端。

⚡ V2.0 质量幻觉危机到分布式管道打包

第一阶段：输出质量瓶颈与 AI 幻觉危机（重构动因）
本项目在初期测试时暴露出了严重的内容合规漏洞。由于最下游的撰写模型处于高发散的“创意模式”，为了追求营销文案的“拉踩爽感”，容易产生严重幻觉——无视事实真相，直接给主打纯牛乳的优秀竞品强加“全杯都是植脂末与化学香精”等虚假缺点。这种失实语料极易给品牌带来致命的法律风控和公关翻车风险，催生了引入硬核事实核对机制的刚需。

第二阶段：多层风控审计带来的 57 秒性能危机与数据安全合并
为了彻底拦截幻觉，我们在工作流终点引入了“精确模式审计大模型”。但多层模型的链式推理使执行 Tokens 消耗飙升至 5612，总响应耗时高攀至 57 秒。长达一分钟的 HTTP 阻塞如果采用不稳定的流式拆分极易由于多字节乱码在前端引发解析崩溃。为了在面试实机演示中实现“100% 数据事务完整性”，2.0 旗舰版采用了**云端事务流强合并打包+前端高保真可视化流水线监控面板**的组合拳设计。

🛡️ V2.0 纯线性 Guardrail 护栏原理

2.0 旗舰版彻底抛弃了臃肿的多路分支拓扑，在云端重构为了极简、确定性极高的**纯线性合规提取流水线**：

[Start] FastAPI 网关接收用户的竞品关键词及目标分发媒介变量。
[Node 1] 舆情清洗 Agent 运作，利用 search_web 插件建立严谨的竞品 JSON 事实画像。
[Node 2] RAG 精确召回层。高维向量提取我方 FreshTea 白皮书参数注入上下文。
[Node 3] 创意撰写 Agent 产出高网感粗稿文案。
[Node 4] **精确合规审查终节点**（核心护栏中间件）。采用精确模式，逐句核对粗稿是否对 Node1 的事实画像进行恶意捏造。最终合并输出标准 JSON 字典。

后端 FastAPI 网关在接收到完整的打包响应后，无损转发给前端。前端的高级感知组件在加载状态下会全速激活 **AI 深度风控流水线实时执行动态面板**，将 57 秒的深度推理过程转化为高可观测性的工业级架构展示，全面提升系统在生产演示中的可用性与技术壁垒。

🛠️ 核心功能与平台矩阵要求

详解各新媒体分发渠道的 Prompt 微调控制与输出调性

🟥 小红书模式 (爆款种种草风)

采用口语化的“闺蜜蜜友式”语境，嵌套高频热梗词汇（如谁懂啊、家人们）。排版每行文本独立成段，穿插高密度 Emoji。前三行制造痛点暴击（喝奶茶失眠、配料表糊弄），中段引入我方成分救赎，底部包装标签，激发用户搜索和高互动。

⬛ 抖音模式 (短视频口播脚本)

输出标准短视频短句子口播。包含明确的【镜头画面描述】（如：特写奶茶杯配料表、手机原生镜头抖动）、【台词口播】以及【音效/BGM建议】。开局 3 秒内安排黄金钩子强行留存，中段反转带货。

🟩 公众号模式 (深度推文大纲)

严谨、客观、具有长媒体科普自媒体号公信力的叙事风格。输出结构包含拟选爆款标题池、金句提炼、理性科学数据逻辑拆解层。通过详尽的数据对比与食品营养学常识建立权威心智。
